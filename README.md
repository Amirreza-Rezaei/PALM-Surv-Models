# PALM-Surv Models in Survival Analysis

This repository contains the R implementation and LaTeX documentation for my B.Sc. thesis project on Partially Additive Linear Model (PALM) Trees for survival analysis.

## Overview
The project focuses on applying and evaluating PALM-Surv models to handle complex survival data, capturing both linear effects and tree-based interactions.

## Usage
The models implemented in this repository follow the specific formula specification order below:
`y ~ x_var | x_fix | z`

## Repository Structure
* `/R`: Contains all R scripts for data processing, model building, and evaluation.
* `/docs`: Contains the LaTeX source code (using `xepersian`) and the final project report.
